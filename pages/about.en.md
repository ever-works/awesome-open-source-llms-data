# About Awesome Open Source LLMs

Awesome Open Source LLMs is a curated, continuously updated directory of open-source large language models and the platforms used to run them. It exists to make a crowded field legible: which models exist, how they are built, how they perform, what their licenses allow and where you can deploy them.

## What you'll find here

- **Models by type** — foundation, instruction-tuned, reasoning, code generation, small, multilingual, multimodal, embedding and research models.
- **Key facts per model** — architecture, parameter count, benchmarks, license and links to weights and papers.
- **Deployment platforms and safety tooling** — inference servers, hosting options and guardrails.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new releases, keep existing listings current and organize everything into categories and tags; every listing links back to its original source.

See a model that's missing or outdated? Use the **Submit** page to let us know.
